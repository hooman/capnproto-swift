Cap’n Proto for Swift, down to bare metal.

An allocation-free, Embedded-clean runtime and a code generator for reading and building Cap’n Proto messages. Readers borrow the bytes instead of copying them, builders write into storage you provide, and malformed input never traps.

Get started API reference Source on GitHub

No allocation

The runtime never touches the heap. The Embedded gate compiles it with -no-allocations, so a stray allocation is a build error.

Lifetimes the compiler checks

Every view is ~Escapable: a reader can’t outlive the bytes it borrows, and a builder can’t be used while a child view is alive.

Fails soft, never traps

A bad field reads its default and records the first error. A build that runs out of space reports the exact size to retry with.

32-bit, tested

Every message, and suites for 32-bit edge cases, run on WebAssembly and on Cortex-M4 and RV32 under QEMU, with host-identical results.

Install

Install the upstream capnp compiler (brew install capnp), then depend on the package and attach its build-tool plugin to a target holding .capnp schemas:

dependencies: [
    .package(url: "https://github.com/hooman/capnproto-swift", .upToNextMinor(from: "@VERSION@"))
],
targets: [
    .executableTarget(
        name: "Demo",
        dependencies: [.product(name: "CapnpRuntime", package: "capnproto-swift")],
        swiftSettings: [.enableExperimentalFeature("Lifetimes")],
        plugins: [.plugin(name: "CapnpGeneratorPlugin", package: "capnproto-swift")]
    )
]

Read

let arena = Arena(framedBytes: bytes.span.bytes)
arena.withRoot { root in
    let person = Capnp_9c3f8a1b2c4d5e6f.PersonReader(root)
    print(person.id, String(copying: person.name.utf8))
}
guard arena.error == .none else { return }  // check after traversal

Build

var message = MessageBuilder(storage: span.mutableBytes)
do {
    var person = message.initRoot(Capnp_9c3f8a1b2c4d5e6f.PersonBuilder.self)
    person.setId(1)
    person.setName("Ada".utf8Span)
}
// .outOfSpace: retry with message.requiredByteCount bytes
guard message.error == .none else { return }
let framed = message.framedBytes
